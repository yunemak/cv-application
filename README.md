# React CV Generator 📝

[Live Demo](https://cv-application-lyart-nine.vercel.app/)

A clean, interactive, and responsive CV application built with **React** as part of [The Odin Project](https://www.theodinproject.com/) curriculum. This app allows users to input their personal information, education history, and work experience with a real-time preview toggle.

## 🚀 Features

- **Component-Based Architecture:** Modular design separated into Contact, Education, and Experience sections.
- **Interactive Edit/Submit Modes:** Users can lock in their inputs or unlock them to make edits.
- **Controlled Inputs:** Form data is synchronized instantly with React state.
- **Live Preview:** Instantaneous visual feedback on the right-hand side as the user types.

## 🛠️ Built With

- **React** (Hooks, State Management, State Lifting)
- **JavaScript (ES6+)**
- **CSS3** (Custom styling, Flexbox)
- **Vite** (Build tool)

## 💡 What I Learned

During this project, I strengthened my understanding of core React concepts:

- **Component Design:** Breaking down a complex UI into manageable, reusable components instead of over-complicating individual elements.
- **State Management:** Utilizing `useState` to handle user inputs and submission toggles.
- **State Lifting:** Passing state and setter functions from parent components (`App.jsx`) to child components to centralize data flow effectively.
- **Event Handling:** Managing form submissions (`onSubmit`) and input changes (`onChange`) cleanly.

## 📦 Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

```bash
git clone [https://github.com/yunemak/cv-application.git](https://github.com/yunemak/cv-application.git)
```

2. Go to project

```bash
cd	cv-application
```

3. Install Dependencies

```bash
npm install
```

3. Run

```bash
npm run dev
```
